# Contributing

Contributions to cleaning, visualizations and reproducibility are welcome.

1. Fork the repository and create a branch.
2. Install `requirements.txt` in a Python 3.12 virtual environment.
3. Run `python analysis.py` and restart/run all cells in the notebook.
4. Explain any change to cleaning decisions or statistical methods in your pull request.

Keep simulated data clearly labeled. Do not upload credentials or private user data.
Keep observed correlations separate from causal claims. Proposed warning thresholds
need validation before they can be described as a working detection system.
